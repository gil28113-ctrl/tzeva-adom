# 🚨 שרת צבע אדום — הוראות התקנה

## מה זה עושה?
- ✅ מושך נתוני התרעות מ-API של פיקוד העורף כל **2 שניות**
- ✅ שולח לכל הדפדפנים המחוברים בזמן אמת דרך **WebSocket**
- ✅ שולח **Push Notifications** — גם כשהאתר סגור!
- ✅ עובד על Windows / Mac / Linux

---

## 📦 שלב 1 — התקן Node.js

1. כנס ל: **https://nodejs.org**
2. הורד את הגרסה **LTS** (הכפתור הירוק הגדול)
3. הרץ את ה-installer ולחץ Next → Next → Install

לאחר ההתקנה, פתח **Command Prompt** (חפש cmd בתפריט) ורשום:
```
node --version
```
אמור לראות משהו כמו: `v20.11.0`

---

## 📁 שלב 2 — הכן את הקבצים

1. צור תיקיה חדשה בשם `tzeva-adom-server` (למשל על Desktop)
2. העתק לתוכה את הקבצים:
   - `server.js`
   - `package.json`
   - תיקיית `public/` עם `index.html` + `sw.js`

המבנה צריך להיות:
```
tzeva-adom-server/
├── server.js
├── package.json
└── public/
    ├── index.html
    └── sw.js
```

---

## ⚙️ שלב 3 — התקן תלויות

פתח **Command Prompt** בתוך תיקיית הפרויקט:
- לחץ ימני על התיקיה בעוד Shift לחוץ → "פתח חלון PowerShell כאן"

המתן עד שיסיים (כ-30 שניות).

## 🌐 שלב 5 — פתח את האתר

פתח דפדפן וכנס ל:
**http://localhost:3000**

האתר יתחבר לשרת אוטומטית!

---

## 🔔 Push Notifications (אופציונלי)

1. פתח את האתר בדפדפן
2. לחץ על **"אפשר"** בבאנר ההתראות
3. הדפדפן ישאל אישור — לחץ **"Allow"**
4. כעת תקבל התרעות גם כשהאתר סגור! 🎉

---

## 📱 שיתוף עם אנשים ברשת הביתית

כדי שאנשים אחרים ברשת שלך יוכלו להתחבר:

1. מצא את ה-IP שלך: פתח cmd → רשום `ipconfig`
2. חפש "IPv4 Address" (משהו כמו `192.168.1.5`)
3. כנסו ל: `http://192.168.1.5:3000`

## ❓ שאלות נפוצות

**למה אני לא רואה התרעות?**
→ אין התרעות פעילות ברגע זה. השרת ממתין. כשתהיה התרעה אמיתית — היא תופיע מיד.

**השרת כותב שגיאות fetch?**
→ בדוק שיש לך חיבור אינטרנט. לפעמים oref חוסם — השרת ינסה שוב.

**איך לראות את ההיסטוריה?**
→ http://localhost:3000/api/history

**עצרתי את השרת — אבדו ההתרעות?**
→ לא! הן שמורות בזיכרון בזמן הריצה. להוסיף שמירה לקובץ — ניתן להוסיף DB.
